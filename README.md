# Sistema de Gestión de Congreso Estudiantil

## Descripción

Sistema desarrollado en Java que simula la gestión completa de un evento de congregación estudiantil. La aplicación permite administrar eventos, espacios, recursos y toda la logística necesaria para organizar un congreso académico.

## Objetivos

- Aplicar principios de Programación Orientada a Objetos en Java
- Implementar un sistema de gestión de eventos completo y funcional
- Desarrollar habilidades en el diseño de arquitecturas de software
- Practicar la gestión de múltiples entidades y sus relaciones

## Tecnologías Utilizadas

- **Lenguaje**: Java
- **Paradigma**: Programación Orientada a Objetos
- **Desarrollo**: Proyecto académico universitario (PUCV)

## Funcionalidades Principales

- Gestión de eventos del congreso
- Administración de espacios y salas
- Control de logística y recursos
- Organización de participantes
- Sistema de registro y asignación

## Estructura del Proyecto

El sistema está diseñado siguiendo principios de POO, incluyendo:
- Encapsulamiento de datos
- Herencia y polimorfismo
- Gestión de relaciones entre entidades
- Manejo de excepciones

## Lo que Aprendí

Este proyecto fue fundamental para consolidar mis conocimientos en Java y Programación Orientada a Objetos. Aprendí a:
- Diseñar sistemas complejos con múltiples entidades interrelacionadas
- Implementar patrones de diseño apropiados
- Gestionar la lógica de negocio de un sistema de eventos
- Trabajar con estructuras de datos para optimizar el rendimiento
- Documentar y organizar código de manera profesional
